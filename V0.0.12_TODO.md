2. Enter prompt, lyrics, settings
3. Click Generate → AI creates music
4. Music auto-separates stems (vocals, instruments, drums, bass, etc.)
5. Stems auto-populate **Timeline** (each as separate track)
6. Stems auto-route to **Mixer** (Track 1 → Mixer Ch 1, etc.)
7. User clicks **Timeline** tab (bottom nav) → sees arranged tracks
8. User toggles Mixer open → sees all channels with faders
9. User clicks track in timeline → opens Piano Roll for editing
10. User clicks Effects button on mixer channel → adds/edits effects
11. User exports final mix (top header Export button)
