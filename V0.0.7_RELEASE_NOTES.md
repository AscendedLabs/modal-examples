## 🔧 Technical Stack

### Backend
- **Platform:** Modal serverless
- **GPU:** L40S (48GB VRAM)
- **Python:** 3.10
- **Model:** ACE-Step (commit 6ae0852b)
- **Dependencies:**
  - torch 2.8.0
  - torchaudio 2.8.0
  - transformers 4.50.0
  - diffusers 0.33.0
  - peft 0.14.0
- **Inference:** 30-60 seconds per generation
- **Formats:** WAV (48kHz stereo), MP3, FLAC

### Frontend
- **Framework:** FastAPI + vanilla HTML/CSS/JS
- **UI Library:** WaveSurfer.js for waveform visualization
- **Storage:** localStorage for library persistence
- **Audio:** Web Audio API (ready for effects processing)
- **Layout:** CSS Grid + Flexbox
- **Design:** Dark theme with accent colors
- **Responsive:** Adapts to 1920px+ desktop layouts

### Infrastructure
- **Cache:** Modal Volume at `/root/.cache/ace-step/checkpoints`
- **Session IDs:** UUID-based tracking
- **API Endpoints:**
  - `GET /` - Main DAW UI
  - `POST /api/generate` - AI music generation
  - `GET /manifest.json` - PWA manifest
