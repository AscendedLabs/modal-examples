### **STEP 2: Add Real Music Generation (Week 1)**

**Option A: Use Replicate API (Easiest)**

```python
# backend/workers/generation_worker.py
import replicate

@app_modal.function()
def generate_music(prompt: str, duration: int):
    # Use Replicate's hosted models
    output = replicate.run(
        "meta/musicgen:...model_id...",
        input={"prompt": prompt, "duration": duration}
    )
    return output
```

**Option B: Use AudioCraft (Self-hosted on Modal)**

```python
# backend/workers/generation_worker.py
from audiocraft.models import MusicGen

model = MusicGen.get_model('facebook/musicgen-medium')
wav = model.generate([prompt], progress=True, top_k=250)
```

**Option C: Use Hugging Face Pipeline**

```python
from transformers import pipeline
pipe = pipeline("text-to-audio", model="facebook/musicgen-medium")
audio = pipe(prompt)
```

**Recommendation:** Start with **Replicate** (simplest), then move to **AudioCraft** for full control.

### **STEP 4: Wire Up Audio Playback in DAW (Week 2)**

```typescript
// src/frontend/audio/audioEngine.ts
import * as Tone from "tone";

class AudioEngine {
  private players: Map<string, Tone.Player> = new Map();
  
  async loadStem(stemUrl: string, stemId: string) {
    const player = new Tone.Player(stemUrl);
    player.toDestination();
    this.players.set(stemId, player);
  }
  
  playAll() {
    Tone.Transport.start();
    this.players.forEach(p => p.start());
  }
}
```

## 🛠️ Debugging Checklist

If something doesn't work:

1. **Frontend won't load?**
   - Check `npm run dev` terminal for errors
   - Clear browser cache (Cmd+Shift+R)
   - Check `src/frontend/index.tsx` exists

2. **Backend won't start?**
   - `python -m venv venv && source venv/bin/activate`
   - `pip install -r requirements.txt`
   - `python -m uvicorn app.main:app --reload`

3. **API requests fail?**
   - Check `vite.config.ts` proxy points to `:8000`
   - Check CORS middleware in `main.py`
   - Use `curl -X GET http://localhost:8000/` to test

4. **Modal workers error?**
   - Check `modal token set-token` configured
   - Check `.env` has `MODAL_TOKEN_ID` & `MODAL_TOKEN_SECRET`
   - Check Modal dashboard for worker logs
