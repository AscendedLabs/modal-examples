# 🎵 AI Song Generator + DAW Studio — v0.1.0

A production-grade AI-powered music creation platform with two-page workflow:
1. **Page 1 (Generator):** Prompt-to-stems music generation
2. **Page 2 (DAW):** Multi-track editing, mixing, and AI-assisted enhancement

---

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ (frontend)
- Python 3.9+ (backend)
- Modal account (for GPU workers)

### Installation

**1. Clone and setup frontend**

```bash
cd /workspaces/modal-examples/frontend
npm install
```

**2. Setup backend**

```bash
cd /workspaces/modal-examples/backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**3. Set up environment variables**

```bash
# backend/.env
MODAL_TOKEN_ID=your_modal_token
MODAL_TOKEN_SECRET=your_modal_secret
S3_BUCKET=your_s3_bucket
API_BASE_URL=http://localhost:8000
```

### Running Locally

**Terminal 1: Start backend API**

```bash
cd backend
source venv/bin/activate
python -m uvicorn app.main:app --reload --port 8000
```

**Terminal 2: Start frontend dev server**

```bash
cd frontend
npm run dev
```

Visit: **http://localhost:3000**

## 🔌 API Endpoints

### Generation
- `POST /api/generate` — Submit song generation job
- `GET /api/jobs/{job_id}` — Poll job status
- `GET /api/stems/{job_id}/{stem_name}.wav` — Download stem

### Projects
- `POST /api/projects` — Create new project
- `GET /api/projects/{project_id}` — Get project details
- `POST /api/projects/{project_id}/import-stems` — Import generated stems

## 🛠️ Development

### Adding a New AI Feature

1. **Create worker** in `backend/workers/`

```python
# workers/my_feature_worker.py
@app_modal.function(gpu="A10", timeout=600)
def process_feature(job_id: str, audio_data: bytes):
    # Your AI logic here
    pass
```

2. **Create API endpoint** in `backend/app/main.py`

```python
@app.post("/api/features/my-feature")
async def my_feature(request: MyFeatureRequest):
    # Call worker
    pass
```

3. **Add UI button** in `src/frontend/components/AIToolbar.tsx`

```tsx
<button onClick={() => callFeatureAPI()}>
  ✨ My AI Feature
</button>
```
