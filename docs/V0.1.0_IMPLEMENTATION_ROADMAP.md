# 🎵 AI Song Generator + DAW — V0.1.0 Implementation Roadmap

**Vision:**  
A complete production-grade AI song generator with a two-page flow:  
1. **Page 1 (Landing/Generator):** Prompt → AI generates stems  
2. **Page 2 (DAW Studio):** Import generated tracks → edit, enhance, layer with AI assistance  

---

## 📊 System Architecture Overview

```
┌────────────────────────────────────────────────────────┐
│ USER INTERFACE LAYER (React + FastHTML)                │

└────────────────────────────────────────────────────────┘
```

## 🚀 PHASE BREAKDOWN

### **PHASE 1: Landing Page + Generation Pipeline (v0.1.0-alpha)**

**Goal:**  Build the song generator front-end + basic AI generation backend.

**Deliverables:**

1. **Page 1: Song Generator UI**
   - Prompt input field
   - Genre/style selector
   - BPM / key / duration controls
   - Generate button
   - Progress indicator (real-time job status)
   - Download/preview stems button

2. **Backend Generation Service**
   - FastAPI endpoint: `POST /api/generate`
   - Input: `{prompt, genre, bpm, duration, style}`
   - Job queue management (Modal workers)
   - Model selection: MusicLM / Magenta / Replicate API
   - Output: 4-6 stems (vocals, bass, drums, melody, other)
   - Store generated audio to S3 / local storage

3. **Database + Caching**
   - Project metadata (name, created_at, stems, BPM, key)
   - Stem storage (S3 URLs or local WAV files)
   - Job history

**Timeline:** 1-2 weeks  
**Dependencies:** Modal, FastAPI, Web Audio API  
**Success Criteria:**  
- ✅ User can enter prompt → generate 4 stems  
- ✅ Progress updates in real-time  
- ✅ Stems downloadable/previewable  

---

### **PHASE 2: DAW Core + Timeline (v0.1.0-beta)**

**Goal:** Build the DAW editor page with track arrangement, mixer, and playback.

**Deliverables:**

1. **Page 2: DAW Studio UI**
   - **Timeline**: Multi-track horizontal scrolling arrangement
   - **Mixer**: Channel strips, volume faders, pan, mute/solo
   - **Transport**: Play, stop, pause, loop, tempo controls
   - **Track Lanes**: 6+ editable audio regions
   - **Waveform Rendering**: Visual audio feedback
   - **Import Generated Stems**: Auto-load from Page 1

2. **Audio Engine**
   - Web Audio API scheduling
   - AudioWorklet for sample-accurate playback
   - Real-time mixing (gain, pan, routing)
   - Tempo sync across tracks

3. **Interaction**
   - Drag/resize regions on timeline
   - Volume/pan automation lanes
   - Snap to grid
   - Undo/redo

**Timeline:** 2-3 weeks  
**Tech Stack:** React Canvas + Tone.js + Web Audio API  
**Success Criteria:**  
- ✅ Import generated stems into DAW  
- ✅ Play back all tracks in sync  
- ✅ Edit regions, adjust levels  

---

### **PHASE 3: AI Enhancement Tools (v0.1.0-production)**

**Goal:** Add AI-assisted editing: vocal tuning, stem separation, mastering suggestions, instrument regeneration.

**Deliverables:**

1. **AI Enhancement Buttons (In DAW)**
   - **Regenerate Vocals**: Submit vocal stem → get new variation
   - **Separate Stems**: Upload mixed audio → get 4-6 stems
   - **Vocal Tuning**: Pitch correction + vibrato suggestions
   - **Auto-Master**: Final mix → AI mastering suggestions
   - **Instrument Swap**: Replace drum kit style, bass character, etc.

2. **Workflow**
   - Select a track → click "Regenerate"
   - Modal AI worker processes stem
   - Results appear as new region on timeline
   - Undo to revert

3. **Backend Pipelines**
   - Stem separation pipeline (Demucs model)
   - Vocal synthesis pipeline (DiffSinger conditioning)
   - Mastering suggestion (EQ/compression curves)

**Timeline:** 2-3 weeks  
**Dependencies:** Demucs, DiffSinger, Magenta models  
**Success Criteria:**  
- ✅ Regenerate individual vocals  
- ✅ Separate mixed audio into stems  
- ✅ Suggest mastering EQ  

---

### **PHASE 4: Advanced DAW Features (v0.1.0-extended)**

**Goal:** Add pro-level DAW features: effects, automation, MIDI editing, voice cloning.

**Deliverables:**

1. **Effects Rack**
   - Insert VST-style plugins (EQ, reverb, delay, compression)
   - Automation curves for all parameters
   - Real-time preview

2. **MIDI Piano Roll**
   - Edit melodic stems as MIDI
   - Grid snapping, velocity lanes
   - Regenerate as new vocal variation

3. **Voice Cloning**
   - Upload user sample voice
   - Clone it for custom lead vocals
   - Store encrypted voice embeddings

4. **Collaboration**
   - Share project links
   - Real-time editing sync (optional: WebSocket)

**Timeline:** 3-4 weeks  
**Dependencies:** ToneJs + custom effect chains  
**Success Criteria:**  
- ✅ Apply effects to tracks  
- ✅ Edit MIDI sequences  
- ✅ Clone user voice  

---

### **PHASE 5: Mobile PWA + Plugin Bridge (v0.1.0-scale)**

**Goal:** Make DAW accessible on mobile; enable VST/AU integration for desktop DAWs.

**Deliverables:**

1. **Mobile PWA Optimization**
   - Responsive timeline (touch gestures)
   - Offline editing mode (IndexedDB)
   - Background sync when online
   - Mobile-optimized mixer

2. **DAW Plugin Bridge (VST3/AU)**
   - Local service bridges DAW host ↔ Cloud AI
   - Send MIDI + stems → cloud → receive AI output
   - ARA sync for timeline sync

3. **Cloud Deployment**
   - Production FastAPI + Redis queue
   - GPU auto-scaling
   - Model versioning & rollback

**Timeline:** 4-6 weeks  
**Dependencies:** Docker, Kubernetes, DAW plugin SDK  
**Success Criteria:**  
- ✅ Works on mobile (iPad, phone)  
- ✅ Works as Ableton/Logic plugin  
- ✅ Cloud jobs scale to 100+ concurrent users

## 🔧 Tech Stack Decision Matrix

| Layer | Choice | Reason |
|-------|--------|--------|
| **Frontend** | React + TypeScript | Component-driven, large DAW community |
| **Audio Rendering** | Canvas + Web Audio API | High performance, real-time playback |
| **State Management** | Zustand | Lightweight, perfect for DAW state |
| **Styling** | Tailwind + CSS Grid | Responsive, fast iteration |
| **Backend API** | FastAPI | High performance, async support |
| **Job Queue** | Modal (existing) | Already integrated, serverless GPU |
| **AI Models** | MusicLM, Demucs, DiffSinger | Production-grade, open-source options |
| **Audio Scheduling** | Tone.js + AudioWorklet | Battle-tested, reliable timing |
| **Mobile** | Service Workers + IndexedDB | PWA standard, offline support |
