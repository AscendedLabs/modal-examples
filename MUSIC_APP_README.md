# Music App v0.0.1

## Prompt 2 Jam - Full Production Multitrack Mobile DAW Ai BandMate in your pocket!

### Description
An AI-powered music production application that transforms prompts into full multitrack productions. Your personal AI bandmate accessible from anywhere!

### Features
- 🎵 Prompt-to-music generation
- 🎚️ Full multitrack production capabilities
- 📱 Mobile-accessible DAW
- 🤖 AI-powered band member assistance
- ☁️ Powered by Modal for scalable cloud execution

### Files
- `test_modal.py` - Main Modal application for music generation
- `run_music_app.sh` - Shell script to launch the music app

### Getting Started
Run the application using:
```bash
./run_music_app.sh
```
